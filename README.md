# UESTC 教务系统助手 —— 安卓 App

**UESTC 教务系统助手**，**安卓 App**，支持 **课表信息、考试时间、考试成绩** 查询，**2026 最新**

- 本仓库 **安卓 App**：<https://github.com/MilLoong/UESTC-EAMS-Helper-App>
- 相关 **Python 命令行工具**：<https://github.com/MilLoong/UESTC-EAMS-Helper-Python>
- **下载 APK**：<https://github.com/MilLoong/UESTC-EAMS-Helper-App/releases/latest>（下载 `UESTC-EAMS-Helper.apk` 后安装）

## 功能概览

| 模块 | 说明 |
|------|------|
| **课表** | 按 **教学周网格** 展示；**左右滑动 / 顶栏** 切周、一键 **回本周**；可切换 **历史学期**；**双指缩放**（默认铺满周一到周日）；显示 **课程时间、教室、教师**；数据 **本机缓存**，离线可看已拉取过的周次。 |
| **考试** | **当前学期** 与历史学期切换；列表展示考试安排（该学期无考试时提示暂无）。 |
| **成绩** | **全部 / 当前学期 / 历史学期** 筛选；列表与 **分项成绩**（平时、期末、期中、实验等）；**均分 / 均绩** 可分别勾选参与计算的课程。 |
| **我的** | 登录后显示 **学号、姓名**；**账号登录 / 退出登录**、**网页登录**、**导入课表文件**；**应用主题**、**课表排版**、**第 1 教学周** 对齐；**上课提醒** 提前时间；**检查更新** 与开源入口；Debug 包可 **试发上课通知**。 |
| **登录** | 学号 + 统一认证密码；若需 **短信二次认证**，按弹窗输入验证码。会话保存在本机；**退出登录** 只清会话，**保留** 本地课表 / 成绩 / 考试缓存。 |
| **网页登录** | 「我的」内打开 **统一认证 / 移动教务网页**，网页登录后 **[导入会话]**，回主页课表点 **[刷新]** 即可（适合 App 内登录失败时）。 |
| **上课提醒** | 后台每约 15 分钟检查 **当天与次日** 本地课表；可在 **[我的]** **自行输入** 提前分钟数（**10 分钟～1 天**，默认 20 分钟）。 |
| **每日课表同步** | 后台约 **每 24 小时** 自动拉取 **当前教学周** 课表；**当天已成功同步过且本地已有该周缓存则不再请求**，避免重复打接口。 |
| **导入课表（备用）** | 无需登录，可在「我的」导入 [WakeUp 课程表](https://www.wakeup.fun/) 按 **树维教务** 教程导出的 HTML，覆盖本地课表；仍支持切周、回本周。 |
| **版本更新提醒** | 启动后约每 12 小时对照 GitHub Releases 检查，并按 **版本号取最新正式版**；有新版本时弹窗提示；**[我的]** 中可手动 **[检查更新]**。 |

## 使用说明

### 登录与会话

1. 打开底部 **[我的]**，点 **[账号登录]**（会话过期时为 **[重新登录]**），输入学号与统一认证密码。
2. 若提示需要短信验证，在弹窗内输入验证码；可 **[重新发送验证码]**（有冷却时间）。
3. 若 App 内登录不成功，可在「我的」点 **[网页登录]**：
   - 在网页中完成统一认证并进入移动教务；
   - 点 **[导入会话]**（工具栏或页面底部）；
   - 返回主页，在 **课表** Tab 点顶栏 **[刷新]**。
4. 已登录时可在「我的」点 **[退出登录]**：清除登录会话与资料，**本地课表、成绩、考试缓存仍保留**。

登录成功后会话 Cookie 保存在 **本机应用私有目录**，进程重启会自动恢复。**请勿将含学号、Cookie 的导出文件提交到 Git。**

### 导入课表（备用，无需登录）

适用于暂时无法登录、或只想离线看课表。流程与 [WakeUp 树维教务简易导入教程](https://www.wakeup.fun/doc/shuwei.html) 前半段相同（在 **电脑浏览器** 操作）：

1. 打开学校 **树维教务** 网页并登录，进入 **课表页面**。
2. 在课表页按 `F12` 打开开发者工具，切到 **控制台**，粘贴教程中的整段脚本并回车，浏览器会下载一个 **`.html` 文件**（实质为课表 JSON）。
3. 将文件传到手机（QQ、微信、网盘等均可）。
4. 打开本 App，底部 **[我的] → [导入课表文件]**，选择该 HTML 文件。

导入后会 **覆盖** 当前本地课表（含此前登录拉取的数据）。可照常 **切换教学周**、点 **回本周**（也可在「我的」手动对齐第 1 教学周周一）。课表页 **[刷新]** 仍会从教务拉取，需先 **登录** 或 **网页登录并导入会话**；仅想更新导入课表时，请重新 **[导入课表文件]**。

### 课表

- 底部 **课表** Tab：查看当前所选教学周的课程网格（默认缩放铺满 **周一到周日**）。
- **左右滑动** 切周；顶栏可 **上一周 / 下一周**、**回本周**，以及选择教学周；菜单可切换 **当前 / 历史学期**。
- **双指缩放** 调整格子；放大后可先页内横滑，到边缘再切周；可用悬浮按钮恢复默认大小。更细的字号 / 行高 / 列宽可在 **[我的] → 课表排版** 调整。
- 首次进入某周时，若本地无缓存会从网络拉取；已缓存的周次切换时优先读本地。
- 顶栏 **[刷新]**：在 **课表 Tab** 下仅 **强制更新当前正在查看的那一周**。

### 考试与成绩

- 底部切换到 **考试** 或 **成绩** Tab。
- 顶栏 **[刷新]** 只更新 **当前 Tab** 对应数据（不会顺带刷新课表）。
- **考试**：顶部学期栏含 **当前学期** 与其它已缓存学期；无安排时提示「暂无该学期考试安排」。
- **成绩**：顶部可选 **全部 / 当前学期 / 历史学期**（当前学期无成绩时也会显示入口并提示暂无）；可查看 **均分、均绩**；每门课展示 **分项成绩**（平时、期末、期中、实验等，有则显示）。**P** 在均分中按 **85 分** 计。
- 每门课可分别勾选是否参与 **均分** 或 **均绩** 计算，支持 **全选**；刷新成绩后 **保留** 仍存在的课程的勾选。

### 上课提醒

- 安装后请允许 **通知权限**（Android 13+ 需单独授权）。
- 应用使用 **WorkManager** 周期性检查 **当天与次日**、本地课表中的下一节课；若距开课时间在 **1～你设定的提前时间** 内（默认 20 分钟，可在 **[我的]** 输入 **10～1440** 分钟），发送一条提醒。
- **[我的] → 上课提醒** 输入分钟数后点 **保存** 或键盘 **完成**。
- 点击通知可回到 App 课表页。
- **Debug 安装包** 的 **[试发上课通知]** 按当前提前分钟数预览正文（如 30 分钟则显示 **[30 分钟后开始（调试预览，提前提醒设定]**）。

### 每日自动同步课表

- 应用启动后会注册 **约每 24 小时** 一次的 **后台任务**（需 **网络已连接** 且 **登录会话仍有效**）。
- 每次执行时拉取 **本学期、校历当前教学周** 的课表并写入 **本地缓存**。
- **去重策略**：若 **今天** 已经成功同步过 **该学期 + 该教学周**，且本地 **已有该周课表缓存**，则 **整次任务不联网**；无本地会话则跳过。不会因校外网络探活失败而清空登录状态（手动 **[刷新]** 仍会在有会话时尝试拉取）。
- 会话失效时后台任务会安静结束，不会弹窗；请重新登录或网页 **[导入会话]** 后，次日周期任务或手动 **[刷新]** 即可恢复。

## 环境要求

- **JDK 17+**（推荐用 [Android Studio](https://developer.android.com/studio) 自带 JDK）
- **Android Studio**（推荐最新稳定版）或 Android SDK + 命令行 Gradle
- **minSdk 24**，**targetSdk 36**
- 网络可访问学校 **统一身份认证** 与 **移动教务**（**校园网** 即可）

## 快速开始

若只需安装使用，可直接从 [最新 Release](https://github.com/MilLoong/UESTC-EAMS-Helper-App/releases/latest) 下载 APK，无需自行编译。

1. **Clone** 本仓库，用 **Android Studio** 打开工程根目录。
2. 连接 **真机** 或启动 **模拟器**，菜单 **Run** 运行，或执行：

```bash
./gradlew assembleDebug
```

3. Debug 安装包路径：`app/build/outputs/apk/debug/UESTC-EAMS-Helper.apk`。

## 构建与发布

- 日常调试：`assembleDebug`；对外 APK 仍为 debug 包，建议配置统一上传证书以免与本机/Android 默认 debug 签名冲突，见根目录 `keystore.properties.example`
- 本工程默认关闭 `assembleRelease` 相关任务；需要发布包时请自行配置签名与 ProGuard。
- 用户安装包见 [UESTC-EAMS-Helper-App Releases](https://github.com/MilLoong/UESTC-EAMS-Helper-App/releases/latest)。

## 技术栈

- Kotlin、Jetpack Compose、ViewModel
- OkHttp + 本地 Cookie 会话
- WorkManager（课表每日同步、上课提醒轮询）
- 部分页面仍使用 ViewBinding（Web 内置浏览器）

Kotlin 源码注释遵循 **Oxygen** 风格，便于阅读与协作。

## 参与开发（欢迎 Fork）

若你是 **UESTC 在校生**，欢迎 Fork 本仓库参与 **安卓端** 改进。

### 建议流程

1. 在 GitHub **Fork** 后 Clone 到本地。
2. 勿提交 `local.properties`、`**/build/**`、抓包目录、含个人信息的 JSON 或 Cookie 导出。
3. 较大改动前可先开 **Issue** 简述方案。
4. 完成后提交 **Pull Request**。

### 可参考的方向

- 课表 UI、提醒策略、离线体验
- 登录 与 会话稳定性（统一认证 / 移动教务 变更适配）
- 性能 与 无障碍

**维护者** 业余维护，课业优先，回复可能不及时。
