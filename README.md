# UESTC 教务系统助手 —— 安卓 App

**UESTC 教务系统助手**，**安卓 App**，支持 **课表信息、考试时间、考试成绩** 查询，**2026 最新**

- 本仓库 **安卓 App**：<https://github.com/MilLoong/UESTC-EAMS-Helper-App>
- 相关 **Python 命令行工具**：<https://github.com/MilLoong/UESTC-EAMS-Helper-Python>
- **下载 APK（v1.0.6）**：<https://github.com/MilLoong/UESTC-EAMS-Helper-App/releases/tag/v1.0.6>（在 **Release** 页面下载 `UESTC-EAMS-Helper.apk` 后安装）

## 功能概览

| 模块 | 说明 |
|------|------|
| **课表** | 按 **教学周网格** 展示；可切换 **周次**、一键回本周；**课程时间、教室、教师** 等；**数据缓存** 在 **本机**，**离线** 可查看 **已拉取过的周次**。 |
| **考试** | 当前学期 **考试安排列表**。 |
| **成绩** | 成绩查询 与 **汇总展示**。 |
| **我的** | 登录后显示 **学号、姓名**；**开源项目 入口**；Debug 包可 **试发上课通知**。 |
| **登录** | 学号 + 统一认证密码；若需 **短信二次认证**，按弹窗输入验证码。 |
| **Web 导入会话** | 内置浏览器打开 **统一认证 / 移动教务网页**，网页登录后 **[导入会话]**，回主页 **[刷新]** 即可使用（适合 App 内登录失败时）。 |
| **上课提醒** | 后台每约 15 分钟检查本地课表；可在 **[我的]** 自定义 **提前 10～60 分钟**（默认 20）内发系统通知（需允许通知权限）。 |
| **每日课表同步** | 后台约 **每 24 小时** 自动拉取 **当前教学周** 课表；**当天已成功同步过且本地已有该周缓存则不再请求**，避免重复打接口。 |
| **导入课表（备用）** | 无需登录，可导入 [WakeUp 课程表](https://www.wakeup.fun/) 按 **树维教务** 教程导出的 HTML 文件，覆盖本地课表；仍支持切周、回本周。 |
| **版本更新提醒** | 启动后约每 12 小时对照 GitHub [最新 Release](https://github.com/MilLoong/UESTC-EAMS-Helper-App/releases/latest) 检查；有新版本时弹窗提示下载，**[我的]** 中可 **[检查更新]**。 |

## 使用说明

### 登录与会话

1. 主页顶栏点 **[登录]**，输入 学号 与 统一认证密码。
2. 若提示需要 短信验证，在弹窗内输入 验证码；可 **[重新发送验证码]**（有冷却时间）。
3. 若 App 内登录不成功，可点顶栏 **[Web]**：
   - 在网页中完成 统一认证 并进入 移动教务；
   - 点 **[导入会话]**（工具栏或页面底部）；
   - 返回主页，点顶栏 **[刷新]**。

登录成功后会话 Cookie 保存在 **本机应用私有目录**，进程重启会自动恢复。**请勿将含学号、Cookie 的导出文件提交到 Git。**

### 导入课表（备用，无需登录）

适用于暂时无法登录、或只想离线看课表。流程与 [WakeUp 树维教务简易导入教程](https://www.wakeup.fun/doc/shuwei.html) 前半段相同（在 **电脑浏览器** 操作）：

1. 打开学校 **树维教务** 网页并登录，进入 **课表页面**。
2. 在课表页按 `F12` 打开开发者工具，切到 **控制台**，粘贴教程中的整段脚本并回车，浏览器会下载一个 **`.html` 文件**（实质为课表 JSON）。
3. 将文件传到手机（QQ、微信、网盘等均可）。
4. 打开本 App，主页顶栏点 **[导入]**，选择该 HTML 文件。

导入后会 **覆盖** 当前本地课表（含此前登录拉取的数据）。可照常 **切换教学周**、点 **本周**（按常见开学日估算当前周，若不准可手动切周）。顶栏 **[刷新]** 仍会从教务拉取，需先 **登录** 或 **Web 导入会话**；仅想更新导入课表时，请重新 **[导入]**。

### 课表

- 底部 **课表** Tab：查看当前所选教学周的课程网格。
- 顶栏可 **上一周 / 下一周**，以及 **本周**（回到校历当前周）。
- 首次进入 某周 时，若本地无缓存会 从网络拉取；已缓存的周次切换时 优先读本地。
- 顶栏 **[刷新]**：在 **课表 Tab** 下仅 **强制更新当前正在查看的那一周**。

### 考试与成绩

- 底部切换到 **考试** 或 **成绩** Tab。
- 顶栏 **[刷新]** 只更新 **当前 Tab** 对应数据（不会顺带刷新课表）。

### 上课提醒

- 安装后请允许 **通知权限**（Android 13+ 需单独授权）。
- 应用使用 **WorkManager** 周期性检查 **当天、本地课表** 中的下一节课；若距开课时间在 **1～你设定的提前分钟数** 内（默认 20，可选 10/15/20/30/45/60），发送一条提醒。
- **[我的] → 上课提醒** 可切换提前时间，设置会保存并在后台任务中生效。
- 点击通知可回到 App 课表页。
- **Debug 安装包** 的 **[试发上课通知]** 按当前提前分钟数预览正文（如 30 分钟则显示 **[30 分钟后开始（调试预览，提前提醒设定]**）。

### 每日自动同步课表

- 应用启动后会注册 **约每 24 小时** 一次的 **后台任务**（需 **网络已连接** 且 **登录会话仍有效**）。
- 每次执行时拉取 **本学期、校历当前教学周** 的课表并写入 **本地缓存**。
- **去重策略**：若 **今天** 已经成功同步过 **该学期 + 该教学周**，且本地 **已有该周课表缓存**，则 **跳过本次网络请求**（手动顶栏刷新不受此限制，仍会强制更新当前查看周）。
- 会话失效时后台任务会安静结束，不会弹窗；请重新登录或 Web **[导入会话]** 后，次日周期任务或手动 **[刷新]** 即可恢复。

## 环境要求

- **JDK 17+**（推荐用 [Android Studio](https://developer.android.com/studio) 自带 JDK）
- **Android Studio**（推荐最新稳定版）或 Android SDK + 命令行 Gradle
- **minSdk 24**，**targetSdk 36**
- 网络可访问学校 **统一身份认证** 与 **移动教务**（**校园网** 即可）

## 快速开始

若只需安装使用，可直接从 [v1.0.0 Release](https://github.com/MilLoong/UESTC-EAMS-Helper-App/releases/tag/v1.0.0) 下载 APK，无需自行编译。

1. **Clone** 本仓库，用 **Android Studio** 打开工程根目录。
2. 连接 **真机** 或启动 **模拟器**，菜单 **Run** 运行，或执行：

```bash
./gradlew assembleDebug
```

3. Debug 安装包路径：`app/build/outputs/apk/debug/UESTC-EAMS-Helper.apk`。

## 构建与发布

- 日常调试：`assembleDebug`
- 本工程默认关闭 `assembleRelease` 相关任务；需要发布包时请自行配置签名与 ProGuard。

## 技术栈

- Kotlin、Jetpack Compose、ViewModel
- OkHttp + 本地 Cookie 会话
- WorkManager（课表每日同步、上课提醒轮询）
- 部分页面仍使用 ViewBinding（Web 内置浏览器）

Kotlin 源码注释遵循 **Oxygen** 风格，便于阅读与协作。

## 参与开发（欢迎 Fork）

若你是 **UESTC 在校生**，欢迎 Fork 本仓库参与 **安卓端** 改进。

### 建议流程

1. 在 GitHub **Fork** 后 Clone 到本地。
2. 勿提交 `local.properties`、`**/build/**`、抓包目录、含个人信息的 JSON 或 Cookie 导出。
3. 较大改动前可先开 **Issue** 简述方案。
4. 完成后提交 **Pull Request**。

### 可参考的方向

- 课表 UI、提醒策略、离线体验
- 登录 与 会话稳定性（统一认证 / 移动教务 变更适配）
- 性能 与 无障碍

**维护者** 业余维护，课业优先，回复可能不及时。
