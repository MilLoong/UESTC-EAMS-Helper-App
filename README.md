# UESTC 教务系统助手 —— 安卓 App

**UESTC 教务系统助手**，**安卓 App**，支持 **课表信息、考试时间、考试成绩** 查询，**2026 最新**

- 本仓库**（安卓）**：<https://github.com/MilLoong/UESTC-EAMS-Helper-App>
- 相关 **Python 命令行工具**：<https://github.com/MilLoong/UESTC-EAMS-Helper-Python>

## 功能概览

| 模块 | 说明 |
|------|------|
| **课表** | 按 **教学周网格** 展示；可切换 **周次**、一键回本周；**课程时间、教室、教师** 等；**数据缓存** 在 **本机**，**离线** 可查看 **已拉取过的周次**。 |
| **考试** | 当前学期 **考试安排列表**。 |
| **成绩** | 成绩查询 与 **汇总展示**。 |
| **我的** | 登录后显示 **学号、姓名**；**开源项目 入口**；Debug 包可 **试发上课通知**。 |
| **登录** | 学号 + 统一认证密码；若需 **短信二次认证**，按弹窗输入验证码。 |
| **Web 导入会话** | 内置浏览器打开 **统一认证 / 移动教务网页**，网页登录后 **[导入会话]**，回主页 **[刷新]** 即可使用（适合 App 内登录失败时）。 |
| **上课提醒** | 后台每约 15 分钟检查本地课表，在 **开课前 1～20 分钟** 发系统通知（需允许通知权限）。 |
| **每日课表同步** | 后台约 **每 24 小时** 自动拉取 **当前教学周** 课表；**当天已成功同步过且本地已有该周缓存则不再请求**，避免重复打接口。 |

## 使用说明

### 登录与会话

1. 主页顶栏点 **[登录]**，输入 学号 与 统一认证密码。
2. 若提示需要 短信验证，在弹窗内输入 验证码；可 **[重新发送验证码]**（有冷却时间）。
3. 若 App 内登录不成功，可点顶栏 **[Web]**：
   - 在网页中完成 统一认证 并进入 移动教务；
   - 点 **[导入会话]**（工具栏或页面底部）；
   - 返回主页，点顶栏 **[刷新]**。

登录成功后会话 Cookie 保存在 **本机应用私有目录**，进程重启会自动恢复。**请勿将含学号、Cookie 的导出文件提交到 Git。**

### 课表

- 底部 **课表** Tab：查看当前所选教学周的课程网格。
- 顶栏可 **上一周 / 下一周**，以及 **本周**（回到校历当前周）。
- 首次进入 某周 时，若本地无缓存会 从网络拉取；已缓存的周次切换时 优先读本地。
- 顶栏 **[刷新]**：在 **课表 Tab** 下仅 **强制更新当前正在查看的那一周**。

### 考试与成绩

- 底部切换到 **考试** 或 **成绩** Tab。
- 顶栏 **[刷新]** 只更新 **当前 Tab** 对应数据（不会顺带刷新课表）。

### 上课提醒

- 安装后请允许 **通知权限**（Android 13+ 需单独授权）。
- 应用使用 **WorkManager** 周期性检查 **当天、本地课表** 中的下一节课；若距开课时间在 **1～20 分钟** 内，发送一条提醒（标题含课名，正文含剩余分钟、开课时刻、教室）。
- 点击通知 可回到 App 课表页。
- **Debug 安装包** 在 **[我的]** 中提供 **[试发上课通知]**：从本地课表 **随机一门课** 预览通知样式（无课表时会提示先 **[刷新]**）；标题带 **[调试]** 字样，与正式提醒区分。

### 每日自动同步课表

- 应用启动后会注册 **约每 24 小时** 一次的 **后台任务**（需 **网络已连接** 且 **登录会话仍有效**）。
- 每次执行时拉取 **本学期、校历当前教学周** 的课表并写入 **本地缓存**。
- **去重策略**：若 **今天** 已经成功同步过 **该学期 + 该教学周**，且本地 **已有该周课表缓存**，则 **跳过本次网络请求**（手动顶栏刷新不受此限制，仍会强制更新当前查看周）。
- 会话失效时后台任务会安静结束，不会弹窗；请重新登录或 Web **[导入会话]** 后，次日周期任务或手动 **[刷新]** 即可恢复。

## 环境要求

- **JDK 17+**（推荐用 [Android Studio](https://developer.android.com/studio) 自带 JDK）
- **Android Studio**（推荐最新稳定版）或 Android SDK + 命令行 Gradle
- **minSdk 24**，**targetSdk 36**
- 网络可访问学校 **统一身份认证** 与 **移动教务**（**校园网** 即可）

## 快速开始

1. **Clone** 本仓库，用 **Android Studio** 打开工程根目录。
2. 连接 **真机** 或启动 **模拟器**，菜单 **Run** 运行，或执行：

```bash
./gradlew assembleDebug
```

3. Debug 安装包路径：`app/build/outputs/apk/debug/app-debug.apk`。

## 构建与发布

- 日常调试：`assembleDebug`
- 本工程默认关闭 `assembleRelease` 相关任务；需要发布包时请自行配置签名与 ProGuard。

## 技术栈

- Kotlin、Jetpack Compose、ViewModel
- OkHttp + 本地 Cookie 会话
- WorkManager（课表每日同步、上课提醒轮询）
- 部分页面仍使用 ViewBinding（Web 内置浏览器）

Kotlin 源码注释遵循 **Oxygen** 风格，便于阅读与协作。
